Conversor Local de Arquivos para Markdown

Utiliza a engine Microsoft MarkItDown executada no seu próprio computador.

⚠️ Processamento Local:
As conversões rodam através do servidor Python executado no seu PC. Seus dados permanecem 100% privados e locais.

📂 Formatos Suportados para Conversão

📄 Documentos
.pdf .docx .pptx
📊 Planilhas & Dados
.xlsx .xls .csv .json .xml
🌐 Web & Texto
.html .htm .txt
🖼️ Imagens & Áudio
.png .jpg .mp3 .wav
📦 Compactados
.zip
⚙️ Como ativar o servidor Python no seu computador

1. Instale as dependências via terminal:

pip install markitdown fastapi uvicorn python-multipart

2. Execute o script do servidor na máquina local:

python server.py

Mantenha o terminal aberto enquanto realiza as conversões no site.
