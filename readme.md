Uma aplicação web moderna para conversão rápida de documentos, planilhas e arquivos estruturados para **Markdown (`.md`)**. O projeto é construído em Python e impulsionado pela biblioteca oficial **MarkItDown da Microsoft**, permitindo a geração de textos limpos e preservando a estrutura de tabelas, listas e títulos.

## 📂 Formatos Suportados

A ferramenta suporta a conversão dos principais formatos de documentos corporativos e estruturados:

| Categoria | Formatos Aceitos |
| :--- | :--- |
| **📄 Documentos** | `.pdf`, `.docx`, `.pptx` |
| **📊 Planilhas & Dados** | `.xlsx`, `.xls`, `.csv`, `.json`, `.xml` |
| **🌐 Web & Texto** | `.html`, `.htm`, `.txt` |
| **📦 Arquivos Compactados** | `.zip` *(extrai e converte o conteúdo interno)* |

---

## ✨ Funcionalidades Principais

- **Suporte a Múltiplos Arquivos:** Arraste e converta vários documentos simultaneamente.
- **Preview em Tempo Real:** Visualize o resultado em Markdown diretamente na tela antes de realizar o download.
- **Histórico da Sessão:** Acompanhe na barra lateral os arquivos que já foram convertidos durante o uso.
- **Interface em Dark Mode:** Design escuro padronizado com a identidade visual do GitHub.
- **Zero Instalação Local:** Processamento 100% executado em nuvem via Streamlit Cloud.

## 🛠️ Tecnologias Utilizadas

- **[Python](https://www.python.org/):** Linguagem principal do projeto.
- **[Microsoft MarkItDown](https://github.com/microsoft/markitdown):** Engine oficial para extração e parsing de documentos para Markdown.
- **[Streamlit](https://streamlit.io/):** Framework para construção e hospedagem da interface interativa em nuvem.
